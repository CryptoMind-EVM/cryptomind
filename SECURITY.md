# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report privately through GitHub's *Security → Report a vulnerability* on this repository, or email
`brief@getcryptomind.com` with the subject `SECURITY`. Include steps to reproduce and the affected version/commit.

We aim to acknowledge reports within 7 days. This is an independent project without a paid bug-bounty program.

## Scope

- In scope: this repository's code and the production site <https://getcryptomind.com>.
- Out of scope: denial-of-service / volumetric testing, social engineering, third-party services we integrate with.

Please do not access other users' data, and stop testing once you have shown the issue exists.

## Not a source of secrets

This repository is a sanitized snapshot. If you find a credential, token or private key anywhere in it,
report it as above rather than using it.
